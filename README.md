# Insider's Eyes — public feed

Generated JSON served over GitHub Pages. **Data only** — the code that
produces it lives in a separate private repository.

| file | what |
|---|---|
| `feed/latest.json` | recent insider transactions, newest first |
| `feed/alerts.json` | the notification-worthy subset |

Source: SEC Form 4 filings, which are public records. Regenerated a few times
a day.

Not investment advice. These are disclosed transactions by corporate
insiders, published by the SEC.
